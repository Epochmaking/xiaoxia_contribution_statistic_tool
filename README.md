# 小夏贡献统计工具

> 这是为小夏量身定做的一款推文数据/稿费统计工具，目前支持一键自动获取某个月发布的所有推文信息以及落款名单，稿费自动统计功能待开发中。

---

## 功能特性

- ✅ **一键获取公众号 BIZ（自动识别，无需手动查找）**
- ✅ **自动抓取目标月份所有推文列表**
- ✅ **逐篇爬取文章内容、阅读量、点赞数、分享数、收藏数**
- ✅ **AI 智能解析文末落款（编辑、排版、图片制作人员名单**
- 🔄 稿费自动统计（开发中）
- ✅ **友好的图形化结果表格，支持点击链接直接跳转原文**
- ✅ **一键导出 Excel（作品清单）**

---

## 使用指南

### 第一步：获取公众号 BIZ

启动程序后，在第一步界面点击 **「开始获取」** 按钮，系统会自动开启代理监听。

![步骤一：获取 BIZ 操作界面](./docs/assets/step-01.png)

随后请在微信电脑版中随意打开一篇本公众号的文章，程序将自动捕获公众号 BIZ 信息并保存。获取成功后，按钮会变为 **「下一步」**，点击进入第二步。

> 💡 小提示：BIZ 是公众号的唯一标识，只需获取一次，程序会自动保存，下次启动可直接跳过此步。

---

### 第二步：抓取目标月份推文列表

在第二步界面中，选择你想要统计的 **年份和月份**，然后点击 **「开始获取」** 按钮。

![步骤二：选择月份并抓取文章列表](./docs/assets/step-02.png)

请复制软件给出的链接，**粘贴在微信电脑版的聊天窗口发送给文件传输助手（或者你的小号）**，点击发送后的链接，会打开公众号的 **「历史消息」** 页面，在**「历史消息」**页面向下滑动触发页面加载，程序会自动捕获分页接口，然后自动抓取该月的所有文章索引。

抓取完成后会弹出提示，点击 **「OK」** 进入第三步。

> 💡 小提示：抓取过程中请勿关闭微信，程序会自动按时间过滤，仅保留你所选月份内发布的文章。

---

### 第三步：爬取文章内容与统计信息

进入第三步后，程序自动启动浏览器逐篇访问文章链接。你可以看到进度条实时更新当前状态。

![步骤三：正在爬取文章内容](./docs/assets/step-03.png)

如果微信触发了人机验证，程序会自动弹出浏览器窗口提示你完成验证，完成后点击弹窗的 **「确认」** 按钮即可继续，浏览器会自动隐藏。

每篇文章会自动获取：

- 阅读量 / 在看数 / 爱心数 / 分享数 / 收藏数
- 文末落款人员名单（文、排版、动图制作等）

---

### 第四步：查看结果与导出

抓取完成后，会自动切换到结果表格页面。

![步骤四：结果表格展示](./docs/assets/step-04.png)

表格包含以下列：

- **发布时间**
- **标题**
- **原创声明** — 小绿书没有声明原创的功能，此处显示“小绿书”
- **内容链接** — 点击「点击访问」可在浏览器中打开原文
- **类型** — 图文 / 小绿书
- **参与人员** — 文末落款原文
- **格式化参与人员** — AI 结构化后的作者名单（勾选「计算稿费」时可见）
- **阅读量** — 超过 10 万自动显示「10万+」（超过 10 万 + 获取详细数字必须通过公众号后台，本软件目前无法获取）
- **点赞数 / 爱心数 / 分享数 / 收藏数**

点击右上角 **「导出文件」** 按钮，选择保存文件夹，即可自动生成 Excel 文件（文件名自动带时间戳）。

> 💡 小提示：勾选 **「计算稿费」** 开关后再抓取，可以开启 AI 对落款名单的结构化解析，输出更精细的作者分工信息。

## 配置文件说明

程序首次启动后，会在程序所在目录自动生成 `xiaoxia_tool_config.ini` 配置文件，包含：

```
- `listen_port` — 代理监听端口（默认 8082，如遇无法正常可以改成其他值比如8083）
- `max_timeout_s` — 接口最大超时时间（秒）
- `max_retries` — 失败最大重试次数
- `fetch_interval_s` — 请求间隔秒数（避免被微信风控拦截）
- `glm_api_key` — 智谱 AI API Key（用于落款解析）
- `glm_model` — AI 模型名称
- `mp_id` — 已获取的公众号 BIZ（自动写入）

一般情况下无需手动修改此文件。如果遇到抓取失败可以适当调整 `fetch_interval_s` 值调大一点或隔几个小时后再试。
```

## 常见问题

**Q: 为什么一直停在「正在获取」没反应？**

A: 请确认微信电脑版是否可以正常访问网络，或点击程序会自动通过系统代理捕获流量。如果长时间没反应，可以点击「停止获取」后重新开始。

**Q: 弹出人机验证怎么处理？**

A: 在弹出的浏览器窗口按提示完成滑动或点选验证后，回到程序点击弹窗的「确认」按钮即可，程序会自动继续。

**Q: 阅读量/点赞数全都是 0？**

A: 可能是微信接口返回失败。可以确认文章是否已发布较长时间，或稍后重试。

**Q: 程序关闭后，电脑无法上网？**

A: 程序正常退出时会自动关闭系统代理。如果异常崩溃导致无法上网，重新打开本软件并退出本软件即可，或手动打开：Windows 设置 → 网络和 Internet → 代理 → 关闭「使用代理服务器」开关即可。

**Q: 结果表格能保留历史数据吗？**

A: 程序关闭后数据不会保留。需要保留数据请点击「确认并导出」导出 Excel 保存。
